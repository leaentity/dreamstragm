# 白纸与细签字笔：视觉 V2

日期：2026-11-06。以用户提供的 Dreamstragm_UI_v2_export.zip 中 style.css、app.js 的视觉标记及两张截图为参考。参考中的业务逻辑、旧 API、服务端和会话代码没有合并。功能与数据仍来自本仓库。

## 设计规则与原因

- 白纸 #fff、墨色 #232321、正文 #2f2f2c、次级 #6f6f6b、浅灰 #f4f4f1：让梦境内容成为主体，不用大色块抢走注意力。
- 手写标题 22–24px、分区标题 17px；正文系统字体 14–16px，行高 1.7–1.9。标题保留私人手札感，长内容以阅读为先。
- 手机页面以 390px 为基准；24px 左右留白，小于 375px 时用 20px；桌面居中保持手机宽度。
- 列表用轻微起伏的细分隔线；需要明确边界的输入、对话、公开预览等用不规则细框；无厚阴影。
- 首页主操作用手绘椭圆，普通主操作用深色细框，次操作浅灰框或下划线文字；选中项用圈线强调。
- 标签为 # 文字，底部导航用线稿 SVG 与细线选中标记；图标统一线宽与圆端点。
- 大留白建立“安静翻手札”的节奏。首页保留日期 → 助手 → 问题 → 说下来 / 写下来的顺序。
- 粉发像素助手使用原始透明 PNG 的 2 倍尺寸，为白纸页面保留一个彩色焦点，统一用于首页、语音、加载、失败、空列表。

## 保留及易用性修正

- 梦境详情进入探索后继续沿用该梦；更换梦境与全局入口行为不变。
- 手动天气、白噪音、语音优先、可留空标题及示例标识保留。
- 所有输入设 16px、按钮通常至少 44px；小屏增加换行和滚动余量，正文颜色比淡化占位字更清楚。
- 对话改为多行输入，长消息自然换行；聚焦输入可滚动到页面可见区域。缩短视口验证通过，但未在真实手机软键盘、来电中断或不同浏览器上验收。
- 切换页面时移除旧提示，避免前一步的保存提示遮住下一页。
- 不新增网络字体；沿参考使用 Noteworthy / Hannotate SC 等系统字体回退。非 Apple 系统可能显示为系统中文无衬线字体，字形不能保证与参考截图完全相同。

## 验证记录

- JavaScript 语法与 git diff 格式检查通过。

- 目视复核首页、记录、整理、失败、探索、长对话、插画结果、统计、公开预览、梦圈、设置和删除弹层截图。截图保存于本地 outputs/paper-ui-v2（不提交 Git）。
- 语音、整理、解梦和生图仍为本地模拟；没有真实 API 验证。数据刷新重置，梦圈为单机演示。没有部署或合并 main。

## 需要用户做的视觉判断

1. 粉发彩色像素助手与白纸细线画面是否协调；目前保留彩色原图，没有擅自改色。
2. 手写标题的感觉和留白是否合适，尤其是实际手机上的首页与长篇梦境。
3. 插画是否继续沿参考采用灰度预览，或之后允许作品以原有色彩展示。
