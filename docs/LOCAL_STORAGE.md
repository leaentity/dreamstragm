# 本地梦境档案 v1

## 已实现

沿用原生 HTML/CSS/JavaScript；新增 storage.js 统一数据层。IndexedDB 数据库为 `dreamstragm-local`，结构版本 1。

- `meta/state` 保存可版本化的实体快照：dreams、tags、dreamTags、assets、cards、posts。
- `blobs` 按附件 ID 保存真实 Blob 文件。图片不再只是 image:true 标记。
- 示例 ID 统一为稳定字符串 `"1"`、`"2"`、`"3"`；新记录使用 UUID。页面选择和附件关联使用同一 ID，不依赖排序或索引。
- 初次空库只初始化一次示例。删除或清空后刷新，不会重新插入示例。
- 每次提交在同一事务写快照和 Blob。写入成功后才更新页面内存、退出编辑或提示成功。
- revision 防止另一个标签页用旧数据静默覆盖新写入；发生冲突时需先复制未保存内容，再刷新重试。

## 一条梦境的关联

Dream 保存 originalText、confirmedText、transcriptText、dreamDate、title、createdAt/updatedAt、contentVersion、versions。

首次原文保存后不再回填或覆盖。编辑页编辑当前正文；每次保存增加正文版本。原文、转写和版本历史可在详情查看。整理确认页保存用户确认后的稿件，跳过整理仍可保存原文。

Tag 保存稳定 ID、名字和类型；DreamTag 记录梦境与用户已确认的标签。旧字符串标签显式映射到人物/地点/主题/事件；未知标签为 unknown，不做自动分析。重复标签只关联一次。

Asset 保存 id、dreamId、sourceVersion、kind、isDemo、style、description、status、createdAt，Blob 单独保存。每次保存图片新增附件，不覆盖旧图；详情展示全部图片。

InterpretationCard 保存 id、dreamId、sourceVersion、god、text、isDemo、createdAt。多次保存会留下多张卡片。当前内容仍为预设示例，没有真实 AI。

删除梦境在同一事务删除其标签关联、私人附件和解读。独立公开快照不受影响。标签目录中无引用的条目不参与页面梦境计数。

## 单机梦圈

帖子和评论也由同一层持久保存。帖子只保存公开文字、公开标签、选定的卡片文字和独立图片副本，不保存私人 dreamId、原文或聊天。关键词模式的正文与预览一致。删除私人梦境不会破坏已发布图片。

这仍是本机演示，不会向其他用户或互联网发布。

## 错误与数据管理

- 保存中禁止重复提交。配额、权限、数据库错误不显示成功；编辑和评论输入保留，可直接重试。
- 离开有修改的记录页会确认；刷新/关闭页也有浏览器提醒。这不是草稿自动保存，浏览器异常退出可能丢失未保存内容。
- 数据无法读取、版本不支持或附件缺失时，不自动清空或重置；显示启动错误与重试。能读到原始快照时可下载恢复信息，该恢复文件不等于包含全部 Blob 的正常备份。
- Settings → Data & reset → Download full backup：下载包含全部实体与附件的 JSON。
- Restore a full backup：验证格式、版本、关联和附件后，一次性替换当前库，需用户确认。最大 30 MB。无效备份不覆盖原库。
- Clear local data：二次确认后清空全部私人数据、附件和本机梦圈，刷新仍为空。
- 原有 Markdown 导出保留，可用于 Obsidian 或手动导入其他工具；完整图片与版本历史用 JSON 备份保存。

只在同一设备、浏览器档案与 origin 下保存。`localhost:5174` 与另一个域名/端口不共享数据；查询参数变化不影响同一份档案。无云同步；清理站点数据、无痕窗口关闭或设备故障可能删除档案。备份包含私人内容，请自行妥善保管。

## 验收与剩余边界

- `node --test tests/storage.test.cjs tests/ambient.test.cjs`：版本保留、多图多卡归属、删除隔离、原子失败、初始化一次、备份恢复、异常版本和并发冲突；以及音频生命周期。
- `tests/storage-browser.cjs`：真实 IndexedDB 保存/刷新/重新打开、编辑不覆盖原文、多附件、单机发布与评论、备份恢复、删除与清空、写入配额异常、拒绝存储、不支持版本保护、独立浏览器档案关闭后重启读取。
- `tests/ui-smoke.cjs`：原有三导航与主要模拟路径回归。
- 所有浏览器测试使用独立档案与虚构内容，不触及用户当前浏览器的档案。

尚未验收真实整理联调；真实解梦/生图/语音、音频录制、聊天持久化、通用草稿自动保存、跨设备同步和真实多人社区尚未实现。音频附件类型留在结构中，但本轮没有录音 UI 或音频写入接口。整理前已补充本地输入保护；真实 OpenAI 联调仍待凭据验证。
