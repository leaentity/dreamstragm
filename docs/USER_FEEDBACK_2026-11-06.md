# 11/6 试用反馈与朋友验收路径

## 已落实

- 保留主页笑脸和核心助手位置，之后可替换角色素材。
- 白噪音播放 / 静音；浏览器本地合成，离开前台暂停。
- 首页笑脸旁的语音气泡可直达语音演示。
- 记录页语音入口置顶，其次为内容、日期、可选标题。
- 移除日志页重复品牌与欢迎语，保留日期，增加手动天气。
- 探索不放欢迎区，三个入口改为解读梦境、生成梦境插画、查看梦境统计。
- 从梦境详情进入探索沿用当前梦境，允许更换；从底部导航进入探索需主动选择，避免误用上次的梦。

## 朋友最终应完成的三条路径

1. 记录梦境 → 真实 AI 整理 → 确认并保存 → 刷新后重新打开。
2. 从该梦境进入插画 → 编辑描述 → 真实生成 → 保存回原梦境 → 下载或分享。
3. 从该梦境进入解梦 → 选择视角 → 真实多轮交流 → 保存结果。

目前仅完成上述页面与本地模拟交互；真实整理、生图、解梦、语音及持久保存仍待实现。现有“分享”主要指单机梦圈公开预览与模拟发帖，插画下载为 SVG 占位图，不能当作已经可给朋友远程试用的线上服务。

## 接下来优先顺序

先完成统一梦境存储与关联 ID，让原文、确认稿、图片和解读结果可靠归属同一条梦境；再建立 OpenAI 共用服务端，依次接整理、生图和解梦。语音录制与转写沿既定排期推进。上述三条路径各自通过真实能力与失败恢复验收后，再开放手机试用地址。
